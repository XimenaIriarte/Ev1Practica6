HTML, CSS, JavaScript y Django

En esta página mostraré información general sobre los temas que se vieron durante el semestre No. 5 de la materia Fundamentos de Porgramación Web.

HTML

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje estándar utilizado para crear la estructura y el contenido de las páginas web. Su función principal es organizar la información mediante etiquetas que permiten agregar títulos, párrafos, imágenes, tablas, formularios, enlaces y otros elementos multimedia. HTML define la base de cualquier sitio web y trabaja junto con CSS y JavaScript para crear páginas modernas e interactivas.

Ejemplo

Permite crear títulos, párrafos, imágenes, enlaces, etc.

Importancia

Además de estructurar el contenido, HTML utiliza etiquetas semánticas como header, nav, section, article y footer, las cuales ayudan a mejorar la organización y accesibilidad del sitio web. También permite integrar formularios para capturar información de los usuarios y conectar diferentes páginas mediante hipervínculos.

CSS

¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje utilizado para diseñar y dar estilo a las páginas web. Gracias a CSS es posible modificar colores, tipografías, tamaños, márgenes, posiciones y fondos de los elementos HTML, mejorando la apariencia visual y la experiencia del usuario.

Ejemplo

Permite cambiar colores, tamaños, posiciones y diseño visual.

Elementos importantes

CSS permite aplicar estilos mediante selectores, clases e identificadores, facilitando la personalización de cada elemento de una página. También incluye herramientas modernas como Flexbox y Grid, que ayudan a crear diseños responsivos y adaptables a distintos dispositivos como computadoras, tabletas y teléfonos móviles.

JavaScript

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado para agregar dinamismo e interactividad a las páginas web. Permite que el sitio responda a las acciones del usuario, realizando tareas como validación de formularios, cambios de contenido, animaciones, cálculos y manipulación de elementos HTML en tiempo real.

Ejemplo

Se usa para botones, validaciones, animaciones y más.

Funciones

Una de las características más importantes de JavaScript son las funciones. Estas permiten reutilizar código y ejecutar tareas específicas cuando ocurre un evento, como hacer clic en un botón o escribir en un formulario.

Uso actual

Con JavaScript se pueden utilizar variables, operadores, estructuras condicionales, ciclos y funciones para desarrollar diferentes funcionalidades dentro de una aplicación web. Además, trabaja directamente con el objeto document, lo que permite acceder y modificar elementos de la página utilizando el DOM (Document Object Model).

Django

¿Qué es Django?

Django es un framework de desarrollo web basado en Python que facilita la creación de aplicaciones web dinámicas, seguras y organizadas. Utiliza el patrón MVT (Modelo, Vista y Template), el cual separa la lógica, la interfaz y el manejo de datos para mejorar la administración del proyecto.

Uso

Con Django es posible crear aplicaciones que interactúan con bases de datos, gestionar usuarios, administrar contenido y generar páginas dinámicas. El framework incluye herramientas integradas para autenticación, administración de datos y manejo de rutas, lo que acelera el proceso de desarrollo.

Ventajas

Además, Django permite trabajar con bases de datos como SQLite y facilita la creación de modelos y migraciones para almacenar información. También cuenta con un panel de administración que ayuda a gestionar registros de manera sencilla. Gracias a su estructura organizada y seguridad integrada, Django es ampliamente utilizado en proyectos web profesionales y escalables.

Comparación

Frontend

HTML, CSS y JavaScript se encargan de lo que el usuario ve en el navegador.

Backend

Django trabaja en el servidor, procesando datos, usuarios y lógica del sistema.
